# Fehlender Caption-Link ist nur ein Caption-Hinweis

Wenn der SessionNet-Link nicht rekonstruiert werden kann, wird ein ansonsten gültiger Beitrag nicht failed und bekommt auch kein zusätzliches Status- oder Warnungsfeld. Die Caption enthält an der Link-Stelle einen deutlichen Hinweis, dass der Link fehlt und manuell ergänzt werden muss; der Rest des Beitrags wird nicht verändert. `status` bleibt `ready`.

Der Grund: Ein fehlender Link ist ein redaktioneller Nachtrag, kein Generierungsfehler. Die Caption ist der richtige Ort für den Hinweis, weil dort auch der Link stehen würde.
