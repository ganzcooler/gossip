# Zwei Beitragsfamilien statt eines generischen Artikels

Eine Sitzung braucht zwei Lesarten: einen schnellen Überblick und einen Deep Dive pro Thema. Wir erzeugen deshalb pro Protokoll genau einen **Summary-Beitrag** (blau, 9:16-Story, Cover + 2–6 Cards) und null bis fünf **Themenbeiträge** (orange, 4:5-Karussell, Cover + 4–7 Content-Slides). Ein gemischtes Format, ein 4:5-Summary oder eine Topic-Story gibt es nicht.

Der Grund ist die unterschiedliche Aufgabe: Die Summary ist ein Service in 30 Sekunden, der Themenbeitrag erklärt einen Punkt in der Tiefe. Das Format folgt der Aufgabe, nicht umgekehrt.
